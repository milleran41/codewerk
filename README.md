# CodeWerk Studio

Официальная витрина готовых программ Andreas Miller.

- Каталог скачивания: https://milleran41.github.io/codewerk/
- Отдельный архив с прежним дизайном: https://milleran41.github.io/codewerk-source/
- Репозиторий архива: https://github.com/milleran41/codewerk-source

Исходники приложений остаются в собственных репозиториях. Этот репозиторий содержит только сайт. Сборка сайта не собирает приложения, не публикует их релизы и не меняет приватность.

## Добавление и обновление программ

1. Отредактируйте запись в `data/projects.json` или добавьте новую с уникальным `id`.
2. Добавьте тексты RU/EN/DE в `catalog-copy.js`, в `projects[id]`: `tagline`, `description`, `sections`; при необходимости `title` и `features`.
3. Положите изображения в `assets/screenshots/`. Укажите `screenshot`, при необходимости `gallery` и `qrImage`.
4. Задайте `order`, `categories`, `searchAliases`, `platform`. Карточки и подробности создаются автоматически, отдельный HTML не нужен.
5. Укажите проверенный `downloadUrl` готового файла либо настоящий `storeUrl`. Для отсутствующего файла используйте `downloadAvailable: false` и `downloadUnavailableReason: "downloadFileMissing"`.
6. Версию, дату, языки приложения и условия распространения заполняйте только по подтверждённым данным: `version`, `updatedAt`, `languages`, `licenseType` (`free`, `freemium`, `paid`), `price` (`amount`, `currency`). Неизвестные значения оставляйте `null` или пустым массивом.

Сайт сохраняет один общий интерфейс. Компактное превью содержит изображение, название, описание и действия. Дополнительные сведения открываются в модальном окне.

Полное руководство: [docs/SINGLE_PAGE_CATALOG.md](docs/SINGLE_PAGE_CATALOG.md).

## Проверка и публикация

Требуется Node.js 22 или новее. Зависимости для сборки не нужны:

```sh
node scripts/build-site.mjs
```

Проверяется JSON, синтаксис JavaScript, переводы, локальные ресурсы, относительные пути и известные шаблоны секретов. Production находится в `dist/`. Его можно просмотреть через любой локальный статический HTTP-сервер.

После обычного commit и push в `main` GitHub Actions автоматически проверяет сайт и публикует только разрешённое содержимое `dist`. В Pages не попадают Git, инструкции обслуживания, служебные файлы и резервные копии. Не кладите секреты в публичный репозиторий, даже если они исключены из Pages.

## Откат

В GitHub откройте Actions > Publish CodeWerk catalog > Run workflow. Выберите `previous-site`, чтобы временно вернуть прежний сайт на основной адрес, или `catalog`, чтобы снова опубликовать современную витрину. Точка сохранения: тег `pre-catalog-2026-11-04`.

История не переписывается. Независимый сайт `/codewerk-source/` продолжает работать при любом из этих вариантов.

## Текущие ограничения

На 2026-11-04 готовые файлы доступны для Кулинарной книги, Timer, Linkora и LinkVault. Для Timer и MixLab добавлены предоставленные владельцем страницы Microsoft Store; прежний недоступный EXE MixLab не используется. Для Kalender Deutschland нужен подтверждённый готовый пакет или страница магазина: архив исходников не используется вместо приложения.

Подтверждённых Microsoft Store и YouTube-ссылок для Кулинарной книги пока нет. Новая локальная версия приложения и опубликованные сборки могут отличаться; сайт показывает это явно. Неподтверждённые цены и версии не указываются.

Существующие Google Forms, отзывы, рейтинг и отправка ссылки сохранены. `docs/download-request-apps-script.js` оставлен из актуальной версии GitHub, включая изменения текста писем. GitHub Pages не обновляет внешний Google Apps Script автоматически.

Workflow построен на [официальной схеме GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).
